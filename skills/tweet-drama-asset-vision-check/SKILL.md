# 资产自动视觉审核

对每个候选图实际查看原图，不能只读提示词或任务状态。审核结果写入 manifest 和独立 review 报告。

## 审核维度

- 角色：身份、年龄、性别、地域、五官、体型、发型、妆容、服装完整度和场次状态；同时必须是 16:9 纯白背景单张设定板，左侧正面半身特写，右侧同一人物同一服装的无头正面、侧面、背面三视图，完整到鞋底。
- 场景：功能、年代、地域、布局、动线、陈设、光线、材质和后续竖屏取景可用性；必须是正常 16:9 空场景单图，不能误用角色设定板排版。
- 道具：类型、形制、尺度、材质、颜色、关键状态和剧情可识别性。
- 通用：真人感、全剧风格一致性、构图、肢体、文字、字幕、Logo、水印和明显生成瑕疵。
- 硬性禁用项：中国国徽、党徽、国旗等国家或政党徽标；军警制服、红袖章、革命标语、领袖画像等革命或政治标志物；人民币、外币等实体纸币或硬币；世界地图或可识别国界地图；天安门、故宫、长城、东方明珠等现实标志性建筑与地标。任一出现即判该资产 failed。

道具必须是正常 16:9 单件单图，不能出现左侧特写加右侧三视图的角色排版。角色审核还要逐项确认左右身份与服装一致、右侧三个人体确实无头且方向分别为正面/侧面/背面；任一排版错误都必须失败并定向重生。

禁用项判定只看画面实际出现且可辨认的内容，不因提示词已声明禁止而放行，也不因题材联想就推定存在。支票、汇票、协议、合同、证件、银行卡等金融或法律文书**不属于现金**，不得据此判失败；无徽标的普通红色布料、包装或装饰同样不判失败。发现禁用物必须指出它在画面中的位置和具体是什么。

证件与文书类道具允许出现剧情必需的金额、日期、姓名，但出现国徽、真实机关名称或真实凭据编号规则时判 failed。

每项记录 pass/fail、分项分数、可观察证据和失败原因。失败时针对原因改写提示词，review_attempts 加一并重生；max_review_attempts=3。三轮仍失败则阻断该资产下游并给诊断，不得自动降低标准。

审核通过只写 asset_status=approved、official=false。随后必须用剧变插件的 `jubian_asset` `confirm_casting` 调用确认出演并回查；只有远端证据成功后才写 asset_confirmation=verified、official=true。镜头与视频只能使用正式资产。
