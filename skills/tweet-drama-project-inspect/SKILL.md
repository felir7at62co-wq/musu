# 仿真人项目检查

只读核对 pipeline_state、磁盘、当前项目/分镜、模型目录及远端任务，不凭目录存在推断完成。报告真实缺失依赖与受影响分支；修复交给对应阶段。

核对当前正式资产身份与归属、必要的确认出演或本地主体门禁证据；核对源文本、说话人、发声方式（对白、旁白、OS）与素材顺序。1–4 秒、9 字/秒、36 字及少旁白是创作建议，超出提示复核，不冒充模型硬限制。请求按当前分镜及实时目录允许时长（包含收束）、比例和分辨率检查，保留已确认交付规格。

pending/unknown 任务继续查询原 ID，模型安排后续回读，不建议盲目付费重提。草稿可继续但明确非最终；最终仅选用 clean/not_required 且有实际文件对应内容、字幕、规格和音画 QA 的视频。核对最终字幕覆盖实际发声而非动作说明，每集 BGM 至少 2 首，按剧情情绪选择并记录选曲理由、时间段和试听记录，最终输出与被审核源文件一致。confirmed failed 的恢复需核对根因、费用及剩余授权，不能无限重试。
