# 仿真人镜头编译

保留源文本、顺序、说话人、发声方式、资产 ID 与材质身份。只绑定当前项目实时主体设定中通过门禁的 official=true 资产；本地匹配不是远端身份的替代。

## 创作建议与真实约束

通常每镜 1–4秒、按 9 个有效字/秒估算；15 字以上可考虑语义拆镜，36 字以上复核可读性与节奏。它们是警告/人工或模型复核，不是普遍硬禁。旁白与心声优先考虑画面表现，但原文要求的发声不删、不强制变成角色当场对白。真实供应商的时长、比例、分辨率和资产限制必须满足。

从项目和当前分镜读取已保存模型、平台、比例、分辨率及请求时长，再以实时模型目录验证。内容预算包含自然收束，不能统一套用14秒加1秒自然收束。对同场景、同时间、同服装、动作连续的完整镜头打包，场景或服装变化切包，不截断原文凑时长。用户确认的交付规格不能被本地默认值覆盖。

## 编译入口

新制作必须使用当前 `drama_shot` 工具，并先读取其 schema：preview/compile 所需 `max_submit_seconds` 来自当前分镜及目录允许的总时长，包含收束；不可盲填 30。可选正整数 duration 表达慢节奏或长镜，`report.warnings` 供节奏复核。VO 使用已支持的 vo 表达并保留说话人及原文；未支持格式报告缺口，不静默降成 dialogue。

当前环境缺少 `drama_shot` 或不能无损表达输入时，保留输入并报告依赖或格式缺口，不修改原文绕过，也不退回把创作建议当硬失败的旧编译器。

## 导演脚本

景别、视角、运镜、空间、动作、情绪、连续性须自洽。无声镜省略台词行，可写 `发声类型：action`；不写假台词 `无`。零人物镜省略出镜人物，不用 `出镜人物：无` 占位。动作复杂度仅按入口支持的标签使用。节奏预算与自然语言提示词分开；提示词一般不堆时间戳，但不把任何秒数视作内容违规。

编译时长仅是计划值，实际视频和字幕时长以生成结果、真实音频及 ffprobe 为准。预计集长可作审片参考，不能凭原剧本标注或字数比例认定最终时长。
