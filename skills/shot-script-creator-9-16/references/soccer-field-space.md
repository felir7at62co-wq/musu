# 足球场与训练场空间参考

当剧本出现足球、训练场、球场、传接球、射门、铲球、边线、中线、禁区、球门、轮胎靶等足球动作或足球场景时，再加载本参考。不要把本参考内容默认塞进所有普通对话场景。

## 空间定位原则

- 足球场参照物少时，用功能区做固定空间点。
- 所有空间点仍然使用`场景图视角 + 具体场景名 + 方位/区域 + 固定功能点 + 靠近/位于中央/远离/之间 + 处`。
- 主体位置写主体在哪里；运镜只写主体、动作和唯一主要运镜，不写相机空间坐标。
- 球路镜头要写清足球、目标点和飞行区域。

## 常用空间点

```md
场景图视角训练场传接球测试点中央
场景图视角训练场测试区中段靠近足球飞行路线一侧
场景图视角训练场远端轮胎靶正前方
场景图视角球场右侧边线靠近中线处
场景图视角禁区弧顶中央
```

## 可扩展写法

```md
场景图视角训练场测试点地面靠近小飞右脚外侧处
场景图视角训练场测试区半空中靠近足球飞行弧线中段处
场景图视角训练场远端轮胎靶中心处
场景图视角球场中线中央靠近开球点处
场景图视角球场左侧边线靠近替补席处
场景图视角球场右侧边线靠近教练区处
场景图视角禁区内靠近点球点处
场景图视角球门前小禁区中央处
场景图视角球门右上死角前方半空中
场景图视角看台前排靠近记者区处
```

## 示例

```md
【镜头1】
景别：特写
运镜：相机固定，小飞右脚脚腕发力，右脚内侧抽中足球
视角：相机视角低角度
主体状态追踪：
【小飞右脚和足球】-位置：【小飞保持单脚支撑射门姿态，右脚位于场景图视角训练场传接球测试点中央靠近地面标线处，足球在右脚前方半步】；
动作状态：【右脚脚腕发力，右脚内侧抽中足球】；
四层朝向链：【右脚朝向远端轮胎靶方向，脚尖转向触球方向，动作焦点落在右脚与足球接触处，发力状态清晰】；
手部状态：【画面不涉及手部】，【无】；
情绪状态：【无】；
发声类型：action
动作复杂度：复杂
无噪点，无跳帧，五官稳定不变形
```

球路跟拍可用“足球在半空中划出弧线飞向画外远端轮胎靶方向，相机摇镜跟随球路”。主体位置以测试区和目标点锚定；若轮胎靶实际入画，运镜与主体状态追踪同时声明足球和轮胎靶，不额外添加相机坐标字段。
